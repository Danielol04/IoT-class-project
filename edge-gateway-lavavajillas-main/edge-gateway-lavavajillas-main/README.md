# edge-gateway-lavavajillas

Gateway local desplegado en Raspberry Pi

## Servicios
- Broker MQTT local (Mosquitto)
- Servicio edge en Python para:
  - control de acceso RFID
  - detección de intrusión
  - envío de comandos a nodos

## Arranque
```bash
docker compose up --build
